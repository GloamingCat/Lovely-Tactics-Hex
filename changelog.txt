# Version v0.3

API changes:
- Fiber is now a subclass of FiberList.
- PopText constructor now needs a manager instead of a renderer.
- EventSheet:setEvent, EventSheet:skipEvents, and EventSheet:jumpTo now only take one argument.
- "args" and "condition" parameters in EventSheet:addEvent were swapped

Method/field renaming:
- TerrainField:setTerrain -> TerrainField:setTerrainId
- Added TerrainField:refreshTerrains
- TerrainLayer.depth -> TerrainLayer.index

New features: 
- New Fiber scope: A Fiber can spawn a new Fiber (fork) as a subfiber.
- New field: EventSheet.skippable.
- New field: Command.unskippable (for event commands within a skippable EventSheet).
- Skip button: if an event sheet is skippable, this button skips commands until an unskippable command is reached (or the end of the sheet).
- FieldManager.updateList now automatically removes objects with "destroyed" tag on.
- New field: TerrainLayer.depth (fixed when the layer is flagged as "background")

Bug fixes:
- Fixed transition animation from one field to another.
